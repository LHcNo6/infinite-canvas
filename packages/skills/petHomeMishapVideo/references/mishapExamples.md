# 三套家庭小糗事完整示例

新创作时读取。以下均为虚构教学故事，未调用 sd25-pe 执行优化、未生成媒体、未验证留存或模型表现。示范按纯文本虚构角色编写，不含附件和素材编号；真实制作须读取本轮导演和定稿技能，按实际宠物与素材重做身份/引用绑定。不可把示范当作用户真实习惯或“本次优化完成”的证据。

Chinese dialogue is teaching material. Create in the user's requested language and budget its natural delivery; preserve approved verbatim wording. The supplied integer intervals are creative budgets, not exact model controls. Verify actual model support before using any runtime below.

每镜先预算自然对白与必要行动，再定镜长，故三套分别为 21、17、16 秒。中文约 4.5 字/秒初估，标点不计；动作可与对白同步，单独占时的必要步骤另列。实际朗读或素材不适配时在授权前重排，不加速、不用尾部静止补齐。

## 一：我的拖鞋为什么总在狗窝里

**机制**：掩饰被诱惑拆穿，交换失败后换一种办法达成目的。虚构主角为赤色柴犬团子、蓝色项圈；喜欢枕拖鞋、抢球是假设。主人只出声音和局部手脚。

**目标与回扣**：狗想继续枕拖鞋睡，最初守住狗窝，最后改为枕主人穿着拖鞋的脚，既有糗事也有亲近。主要场景为低矮狗窝旁；一只米色拖鞋、一只黄色吱吱球，不凭空增加另一只鞋。主人、球、狗窝的相对方向稳定。

**完整对白**：主人“团子，我的拖鞋呢？”团子“我刚睡醒，没看见。”主人“起来，让我找一下。”团子“别翻，我还要睡呢。”主人“这个球谁要？”团子“我要！别扔！”团子“拿球换一下，我还没睡够。”主人“拖鞋本来就是我的。”团子“行，你穿着，我连你一起枕。”

| 镜头 | 自然说话预算 | 必要动作、接续与余量用途 |
| --- | --- | --- |
| 0–4 秒 | 主人约 1.8 秒；狗约 1.6 秒；接话约 0.2 秒 | 主人问话时狗用鼻子把鞋往垫下推、趴住；回答时不再含鞋。鞋边可见，隐藏行动与前半句提问同步；余量为转入答话的自然发音弹性。 |
| 4–8 秒 | 主人约 1.6 秒；狗约 1.6 秒；接话约 0.3 秒 | 手从窝旁伸向垫边，狗听问时已把身体压低、前爪挡住手；挡手与答话同步，保持动作压力而非另留展示。余量为伸手引发挡手的短因果反应。 |
| 8–12 秒 | 主人约 1.1 秒；狗约 0.9 秒；接话约 0.2 秒 | 主人在窝右侧捏响球并放在近处地面，狗答话中起身向球迈一步，鞋随身体离开显露；随后主人取鞋约 1.2 秒，剩余用于捏响/放球触发和移动交接。不是问一句后等满四秒。 |
| 12–17 秒 | 狗约 2.4 秒；主人约 1.8 秒；接话约 0.3 秒 | 狗答话时用鼻子把地上球推向主人作为交换，主人回应中把鞋放到自己脚边；不要求狗叼球说话。余量用于球到手边、鞋落地的必要交接。 |
| 17–21 秒 | 狗约 2.4 秒 | 主人先穿入鞋约 1.2 秒；狗靠近与答话同步，末句中把下巴枕上鞋面，约 0.4 秒完成重心落下即结束。无额外闭眼保持。 |

**详细模型定稿写法示范**：

~~~text
【生成目标】
写实家庭轻喜剧。赤色柴犬团子戴蓝色项圈，偷偷把主人的米色拖鞋当枕头，被黄色吱吱球引开后露馅；交换失败，它改枕主人穿着拖鞋的脚。保留真实犬类四足、口鼻和爪形。

【主体与关系】
全片同一只柴犬。主人在画外，只让同一人的手和脚在必要范围出现。低矮狗窝靠沙发，主人位于窝的右侧，球最终落在窝右前方近处；唯一一只米色拖鞋从窝垫下转到主人脚上，黄色球始终是同一只。柔和室内自然光稳定。主人为平静略无奈的画外声，狗为认真嘴硬、见球突然兴奋的画内声；轮流说话，自然接续。

【事件脚本】
镜头1，0–4秒：平视中景，狗窝、狗头与前爪以及垫下露出的鞋边可见。主人画外问：“团子，我的拖鞋呢？”狗在听问时用鼻子把鞋向垫下推，随即趴住，抬眼自然接答：“我刚睡醒，没看见。”鼻子推鞋发生在答话前，狗不含物说话；目光移向主人伸来的方向，动作接入下一镜。

镜头2，4–8秒：同侧略近中景承接视线，主人的手从右侧伸向窝垫，画外说：“起来，让我找一下。”狗听到“起来”就压低身体，一只前爪轻挡那只手，接答：“别翻，我还要睡呢。”身体遮挡鞋，仍保留开场鞋边的位置；前爪挡手与答话同步，不恢复端坐。

镜头3，8–12秒：同侧稍宽中景，看见狗窝右前方。主人撤手，在右侧捏响黄色球，边说“这个球谁要？”边把球放到近处地面。狗立刻转向球，兴奋接话：“我要！别扔！”说话中起身迈近一步，原先压住的米色拖鞋显露。主人随后从原窝垫处取出这只鞋，狗已到了球旁；先展示离窝造成露鞋，再取鞋，保持连续因果。

镜头4，12–17秒：低机位中景承接狗在球旁、主人已拿到鞋的状态。狗用鼻子把球推向主人，抬头说：“拿球换一下，我还没睡够。”主人边把鞋放在自己脚边，边自然回应：“拖鞋本来就是我的。”球留在主人脚旁，鞋没有回到窝里，狗看着鞋跟近。

镜头5，17–21秒：同侧低机位近景，主人将脚穿入地上那只鞋。狗顺着上一镜靠近，边低头边说：“行，你穿着，我连你一起枕。”下巴在末句中落到穿着拖鞋的脚面上，身体留在地上。改变办法后终于获得枕头，动作完成即结束。

【保持一致】
台词仅由各自说话者说出，主人全程画外发声，狗只在自己的台词时开口；自然呼吸接话，不抢话。球的吱吱声、爪步、鞋落地和室内环境声跟随真实动作。镜头承接相同位置、光线、项圈和道具归属，行动正常速度推进。
~~~

**可替换**：真实昵称、宠物实际喜欢的可安全展示玩具、主人家庭用语、真实睡姿；换道具时重算揭示与转移，不能只替换名词。

**主要风险与验收**：模型可能把遮挡写成鞋消失、让狗含球讲话、让鞋回窝或多出一只。必须看到“压住→离开→露出→取走→穿上→下巴枕脚”的唯一物体状态链；台词准确也不能替代这条因果。21 秒是教学预算，未验证节点支持该规格。

## 二：纸不是我拆的，我在收拾

**机制**：补救制造更明显的现场，借口和行动相互拆台。虚构主角为银灰虎斑猫米粒，无项圈；好奇、想掩饰是假设。主人画外，不加入第二只宠物。

**目标与回扣**：猫想把自己拨落的纸收起来；拉纸让现场变长，坐上去遮挡又失败，结尾仍在试图拉回纸。只有一个客厅桌边，一卷纸及其连续纸带，不让纸进嘴或缠住身体。

**完整对白**：主人“你在干什么？”猫“帮你把纸收起来。”主人“那地上怎么越来越多？”猫“等一下，这张还连着呢。”猫“你先别过来，我压住了。”主人“压住什么？”主人“我是问，谁拆的纸？”猫“先别追责，我在收拾。”

| 镜头 | 自然说话预算 | 必要动作、接续与余量用途 |
| --- | --- | --- |
| 0–4 秒 | 主人约 1.1 秒；猫约 1.6 秒；接话约 0.2 秒 | 猫从低桌边拨落纸卷，落地约 0.5 秒，主人听声开始问；猫已在桌边地上，伸爪够连续纸端，与答话同步。余量用于落地触发提问和明确纸端。 |
| 4–9 秒 | 主人约 2 秒；猫约 2 秒；接话约 0.3 秒 | 同机位或同侧切近，猫拉纸端，卷筒随牵引转动，铺开纸带越来越长；过程与整段对白同步。余量用于第二次拉动后发现仍相连，不另留呆看。 |
| 9–13 秒 | 猫约 2 秒；主人约 0.9 秒；接话约 0.2 秒 | 猫见主人靠近，用身体挪到已有纸带上坐住，必要移动约 0.6 秒；坐下遮住中间、两端仍露出。说话与大部分挪身同步，余量为露出的纸带让主人追问。 |
| 13–17 秒 | 主人约 1.6 秒；猫约 1.8 秒；接话约 0.2 秒 | 主人伸手提起旁边卷筒少许，连着的纸带随之抬起。猫在回答中伸爪拉回纸端，卷筒又转一点，揭示“收拾”仍使纸展开；动作与对白同步，完成即结束。 |

**详细模型定稿写法示范**：

~~~text
【生成目标】
写实家庭轻喜剧。银灰虎斑猫米粒把纸卷拨落，想把纸收回却越拉越长，试图坐住现场，最后辩称在收拾时又拉开一点。猫保持四足、猫爪与真实体型，动作来自好奇和掩饰。

【主体与关系】
同一只无项圈银灰虎斑猫，主人仅为画外声及最后伸入的一只手。低桌靠客厅墙，猫全程在桌边地面活动；开场纸卷在低桌边沿，落到猫右前方地面。只有同一卷纸，纸端、展开的纸带与卷筒始终连续相连；纸不进入嘴部或缠绕身体。主人声音温和疑惑，猫的画内声认真、越说越心虚，均保持同一音色。

【事件脚本】
镜头1，0–4秒：低机位中景同时看见低桌边沿、猫的前爪和地面。猫站在桌旁用前爪拨到纸卷，卷筒落到右前方地面并展开一小截纸端。落地声引来主人画外问：“你在干什么？”猫已经低头伸爪够纸端，抬眼自然回答：“帮你把纸收起来。”动作接续到下一次拉纸。

镜头2，4–9秒：同侧略近中景，猫、纸端和卷筒都留在画内。猫把纸端向自己拨，卷筒转动，连续纸带铺得更长。主人边看它拉边问：“那地上怎么越来越多？”猫看见纸仍连着，又拨一下，立即接答：“等一下，这张还连着呢。”两次拉动产生可见的新长度，不用反复小表情代替变化。

镜头3，9–13秒：同侧中景承接地上已有纸带。听到主人靠近的脚步，猫挪身坐到纸带中间，急着说：“你先别过来，我压住了。”纸带两端仍露在身体外，右侧卷筒原位可见。主人自然追问：“压住什么？”猫的视线跟着右侧伸来的手，身体不归位。

镜头4，13–17秒：同侧稍近中景，猫、纸带和右侧卷筒同时可见。主人手提起卷筒少许，连着的纸带被带起，画外问：“我是问，谁拆的纸？”猫盯着抬起的纸端，边伸爪拉回，边认真接答：“先别追责，我在收拾。”卷筒随拉动又转一点，纸仍与它相连，露出所谓收拾又在拆纸的事实，动作完成即结束。

【保持一致】
所有拉动都发生在同一卷纸和相连纸带之间，物体不复制或瞬间复原；猫只用前爪拨拉和坐姿掩饰。纸声、落地声、脚步与动作对应，主人画外说话，猫仅说自己的台词。镜头按纸的变化连续接续，答话自然衔接。
~~~

**可替换**：昵称、真实的“越帮越忙”习惯和主人常用语。替换成洗衣、做饭等复杂操作会改变负载，应重新创作，不套原动作。

**主要风险与验收**：纸卷旋转和纸带连续关系较难；审片要看拉动确实增加长度，猫坐下只遮中间，提卷时仍相连。若纸的物理关系持续失败，先提出简化动作方案，不自动改题或重生成。17 秒参数需实际模型核对。

## 三：叫主人起床，自己先睡着了

**机制**：催促者被诱惑反噬，职责通过结尾重新解释。虚构主角为白色长毛猫年糕、浅棕耳尖；爱催早饭、喜欢摸头是假设。主人不露脸，只出画外声、手与被子边缘的身体动作。

**目标与回扣**：猫为了早饭催主人起床，摸头让它放弃坚持；主人终于起床，猫却接班睡觉。单卧室、同一床被，不添加闹钟数字或屏幕文字承担剧情。

**完整对白**：主人“再睡五分钟。”猫“不行，早饭都迟到了。”主人“那你也躺一会儿。”猫“我就监督一下。”主人“不是监督吗？”猫“手别停，我还醒着。”主人“行，我起来了。”猫“你先去，我替你睡着。”

| --- | --- | --- |
| 0–4 秒 | 主人约 1.1 秒；猫约 1.8 秒；接话约 0.3 秒 | 猫开场已在床上，前爪轻拍被面，提问与拍被同步，回答时身体前倾。余量用于主人声音引发猫再拍一次，而非拍完等答。 |
| 4–8 秒 | 主人约 1.6 秒；猫约 1.3 秒；接话约 0.3 秒 | 手从被边摸头，猫口头坚持监督却降低前半身，约 0.6 秒必要姿态变化主要在话尾发生；不单独留闭眼镜头。 |
| 8–12 秒 | 主人约 1.1 秒；猫约 1.6 秒；接话约 0.3 秒 | 手先停下，猫立即睁眼抬头，约 0.7 秒的停手→追手证据；主人问时猫已经以头蹭向停住的手，答话后手接着摸。余量用于重新接触。 |

**详细模型定稿写法示范**：

~~~text
【生成目标】
写实温暖家庭轻喜剧。白色长毛猫年糕有浅棕耳尖，原本催主人起床准备早饭，结果被摸头哄得趴下；它用监督作借口，最后主人起床，它替主人继续睡。保留真实猫形与自然前爪动作。

【主体与关系】
同一只年糕在同一张床的被面上，主人在画面左侧被子内，不露脸，只有手和被角变化参与。窗光从右侧稳定照入。猫最初站在被边朝左看主人，后来在原处降低身体，不换床或突然移位。主人为困倦后渐醒的画外声，猫为认真催促、随后放软的画内声。

【事件脚本】
镜头1，0–4秒：床面高度的平视中景，年糕已站在被子上，用一只前爪轻拍左侧被面。主人画外含糊说：“再睡五分钟。”猫听着继续再拍一下，随即认真接答：“不行，早饭都迟到了。”目光盯着主人，身体前倾，下一镜直接承接同一姿态。

镜头2，4–8秒：同侧略近中景，主人从被边伸手摸年糕头顶，画外说：“那你也躺一会儿。”猫嘴上接答：“我就监督一下。”身体却随着摸头降低前半身，前爪自然收近，话尾已经快趴下。摸头和答话同时发生，前爪仍是猫爪，姿态变化连到下一镜。

镜头3，8–12秒：保持同侧，头部和主人的手都清楚可见。主人先停住摸头，问：“不是监督吗？”猫立即睁眼抬头，头主动追向那只停住的手，自然接答：“手别停，我还醒着。”手在答话尾部恢复摸头，猫又放松一点；停手、追手、恢复接触构成证据。

镜头4，12–16秒：回到同侧稍宽中景，主人收手起身，被角随动作抬起，画外说：“行，我起来了。”猫没有继续催，边把头落回原来趴的位置，边柔声接答：“你先去，我替你睡着。”末句中完成趴下，回扣开头的叫醒任务，动作完成即结束。

【保持一致】
主人只说自己的画外台词，猫只说自己的画内台词，音色稳定，问答与表演自然交接。被面轻响、摸毛声和房间环境声随动作发生。摸头只接触同一只猫的头顶，猫主动追手和趴下，不出现人形站立、手持工具或额外宠物。
~~~

**可替换**：真实昵称、催主人做的事、真实偏爱的摸法；替换后保持“催促→诱惑→身体暴露→职责反转”的推进，不把所有宠物都写成黏人。

**主要风险与验收**：手与毛发接触、停手后主动追手、主人起身和猫趴下的连续性。必须看到目标如何被摸头改变；整段只有趴着说话不算完成。16 秒及音画能力需实际节点核对。
