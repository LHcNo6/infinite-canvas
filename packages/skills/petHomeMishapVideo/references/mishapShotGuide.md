# 家庭小糗事：逐镜预算、SD 定稿与读回复核

编写完整分镜、模型提示词或修订节奏时读取。完整故事和三条定稿写法示范见 [家庭小糗事示例](mishapExamples.md)。示例未经生成或实际跨技能运行，正式制作不能照抄“已优化”。

## 从内容推导时间

先写对白和必要行动，后分镜，不先画出若干五秒格。给每镜明确的有效信息：宠物目标、受阻、改变方法、证据或结果。每镜至少 4 秒，一镜可含完整交流及同步动作；单句足够长才独占对白镜头。自然纯动作证据可以成立，不给所有无声区间硬加对白。

逐镜交付下表字段，填真实内容而非空模板：

| 字段 | 完成条件 |
| --- | --- |
| 镜号/连续区间 | 根据自然内容预算，至少 4 秒，起止无漏段；单次总长不超过工作流和模型范围 |
| 逐句对白/自然估时 | 说话者、原文、语气、画内外；中文约 4–5 字/秒初估，已有音频用实际时长 |
| 呼吸和接话 | 普通交流约 0.2–0.5 秒自然接续，不抢话；提问时听者已经反应 |
| 同步动作 | 写明在哪一句中进行，计算时与该句取共同占用区间，不把同一时间相加 |
| 单独占时动作 | 必须先后发生的接近、接触、移动或揭示，说明必要性与自然估时 |
| 剩余时间用途 | 用于哪一次新信息、证据或动作完成；发音弹性限于合理短余量，不拿它吞掉数秒 |
| 交接 | 此镜末的姿态、视线、道具位置/归属、声音怎样直接进入下一镜 |

超过约 0.5 秒的无对白区间说明用途，不能直接判为错误或自动删掉。动作是否承担信息比有无声音重要。时间数字是创作预算，不证明模型准确执行。若朗读超时或动作无法在预算内完成，先重排镜长、合并或在允许范围重写；逐字定稿和固定总时长冲突时交用户选择，不吞字或静默扩写。

## 把动物表演写进每镜

每镜正文保留：景别/机位和必要构图、主体与道具空间、刺激→视线/身体反应→行动过程→可见结果、说话者与逐字台词/语气、对白与行动同步位置、跨镜终态。空间用狗窝、床沿、门、桌等稳定物定位，不仅写“左边/右边”。全片身份、光线与音色可以统一写一次，但各镜的因果和交接不能压缩成梗概。

关键道具按唯一状态链复核。拖鞋例为“窝垫遮挡→身体离开→原处露出→主人取走→脚边放下→穿上→狗下巴枕住”；球负责诱惑和交换，不承担鞋的身份。纸卷例需让卷筒、连续纸带和拉动关系可见；开头没建立的物体不能只靠台词突然出现。

不要同时要求口中含物和说话。把推、叼、放下、开口按真实身体条件排序，允许鼻子/爪子动作与说话合理同步。主人局部动作也有起点与终点，不给两只不同手分配同一个瞬时动作或凭空变出物体。

## SD 专用定稿的交接

Seedance 2.5 必须实际读取全局 `sd25-pe` 主文件；这份指南不是它的替代品。交给优化器完整故事契约、真实素材职责、逐字对白、逐镜预算与上述详细分镜，明确本工作流要求保留已有整数秒创作区间。优化器采用其当次模板，返回一条完整可提交正文。

本工作流优先于上游“目标更长就放慢动作或停顿”的建议：内容不足返回创作阶段补有效信息或重排时长，已有定稿冲突交用户选择。不要从总时长制造空镜，也不要只加“节奏紧凑”而保持原来的稀疏分配。非 Seedance 2.5 使用实际模型适配器，不能假称 SD 专用优化。

模型正文保留真实素材映射、剧情与表演；总时长/比例/分辨率/声音开关、内部预算估算及来源记录留在正文外。平台 `{{ref N}}` 按真实有效输入顺序映射，身份图不是硬首帧。`data.referenceOrder` 为可选字段：缺省保留有效输入顺序；存在当前输入端口排序时，以 `encodeURIComponent(JSON.stringify([source, sourceHandle]))` 为键，从排序表构建索引 Map（重复键保留最后索引）；比较值为该键索引或缺省 Map.size，相同值保持有效输入原序。历史重复边也按此规则处理，不能简单把所有未列项移到末尾。有效顺序无法确认时请用户核对，不猜编号或把缺省当配置错误。未就绪素材在方案中列指定节点与职责，输出后重新核实，不造假编号。

优化后逐镜对照：台词没有被摘要或扩写，说话人和画内外归属不变，刺激和关键动作证据仍可见，道具不复制或归位，镜内动作/接话和跨镜状态完整。缺项先按原范围修订。已经 SD 定稿不再交通用适配器改写。

## 节奏错误与修订方向

| 失效写法 | 具体问题 | 修订方向 |
| --- | --- | --- |
| 0–5 秒主人问“鞋呢”，5–10 秒狗答“不知道” | 短句被强制分到两块，模型可能等到第五秒才答 | 同镜自然问答并同步藏鞋行动，按完整内容预算 |
| 狗说完闭嘴，保持到下一镜 | 说话归属变成独立等待任务 | 明确谁说话、谁倾听并同步反应，回答后直接接行动或下一句 |
| 花五秒转耳、歪头、看鞋 | 微表情没有新的证据或选择 | 显示寻找/遮挡/转移等实际变化；不足则合并，不拉长小动作 |
| 开头写“快节奏”，正文仍每句占五秒 | 形容词没有改变台词与时长分配 | 重新分配逐句、动作与接话预算，重写具体镜头 |
| 每镜都有动作，所以自动算满 | 未区分同步动作和单独占时，可能重复计时 | 分开列两者，标明必要动作的起止及结果 |
| 优化后仅剩“狗坐着，主人问话” | 景别空间、遮挡、诱惑和道具归属被删 | 把导演每镜细节保留到完整最终正文，逐项对照 |
| 已查技能目录，沿用上一条提示词 | 没有实际读取当前正文与规则 | 本条重新读取入口/阶段资料/定稿技能，记录真实来源 |
| 节点有视频路径，因此台词和节奏通过 | 技术成功代替了内容检查 | 实际看听完整视频，列未检查范围；抽帧/低音量只辅助定位 |

## 写入与交付完成条件

在已有故事/方案中保存四类实质成果：完整故事/逐字对白；逐镜预算/详细分镜；模型定稿全文；真实读取的 name/scope/版本字段/资料路径和回退、更新失败、未完成项。上游仅输出正文时，由调用工作流在正文外记录来源，不把收据塞进模型提示词。

首次交互授权前核对完整创作内容、模型声明、参数与实际素材；待生成参考只需列明指定资产节点、职责及输出后的绑定规则，允许其尚无输出。获得本批明确授权后才生成必要图片。素材就绪后完成真实连线、referenceOrder 映射与参数读回，写入视频节点后读回全文，对照每镜关键内容和真实参考绑定，核对实际输出仍符合授权方案，全部通过再调用视频生成。遗漏、空等或不支持的参数先解决；实际修改超出已有授权时重新确认，不以尚未获准生成的图必须已有真实绑定作为首次授权前提。preflightCanvas 负责技术准备，不能证明分镜密度或笑点。

实际成片分别核对画面、声音、事件顺序、道具连续、接话和结尾；只看部分帧、未听音或只能确认播放时如实说明。SD 优化、预算和工作流指令提高可审阅性，不是程序级强制锁或模型效果保证。修订建议不授权重生成。
