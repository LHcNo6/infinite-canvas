# Production evidence in Infinite Canvas

For a substantial generation, record the established story, actual model and input mode, complete current prompt, ordered reference roles, visible start/action/end, likely misread, actual continuity evidence, sound, acceptance criteria, stop condition and remaining uncertainty.

Use the calling workflow's available production tools and revision rules. Do not create a second JSON receipt or require an external script when the platform already owns the record. For a simple text draft, state these decisions only to the depth the request needs; do not invent media, hashes or observations.

Changed prompts or references require rechecking the affected authorization and production record. A completed record is preparation evidence, not proof of artistic quality, model compliance, footage review or user adoption. Missing capabilities go back to the caller under its actual workflow rules.
