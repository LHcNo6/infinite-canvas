# 宠物拟人讲段子创作

根据用户的宠物图片、性格、话题或已有段子，创作一段宠物拟人口播。独立调用只交付文字；由工作流调用时返回台词、表演与资产需求，不操作画布或生成媒体。用户提供的原文和定稿优先，只改用户要求的部分。

## 创作

1. 区分图片可见身份、用户提供的性格和新提议；图片不可读时不假称看过。默认保持物种、脸型、体型、毛色和明显斑纹，以宠物的视角和性格讲话；服装或更强拟人造型由用户指定。
2. 没有话题时选择一个容易理解的日常处境，写一段有明确观点和包袱的原创口播：建立处境或预期，展开宠物的想法，在结尾给出有具体反差的包袱并留停顿。不要用“很好笑”、笑声或解释代替包袱，也不要为了凑时长堆砌事件。用户提供段子时保留原文和笑点，不擅自改写。
3. 先单独检查文字：脱离画面能否听懂，铺垫是否支持包袱，包袱是否清晰且落在合适位置；不声称保证好笑。根据台词长度和停顿安排可说完的时长，不强塞过密台词。默认中文、竖屏、约 20 秒，上限 30 秒；用户指定优先。
4. 默认一只宠物画内说话，以稳定机位、视线、简单表情和少量自然动作配合台词，标明说话者、逐字台词、语气、时间和包袱后的停顿。保持动物结构，避免复杂肢体或道具动作抢占口播。用户指定旁白、其他语言、角色或表演方式时遵从。
5. 提供实际声音目标和验收点；音色、逐字准确度、口型和停顿是否成功须观看听取成片确认，不假定模型支持或表现可靠。已有宠物图优先复用，场景参考只在需要时提出；不要编造图片内容、引用编号或模型规格。

## 交付

给出标题、时长和画幅、宠物身份锚点、可单独阅读的完整逐字台词、铺垫与包袱、按时间排序的表演及声音、资产用途、生成难点和验收点。最终模型提示词由工作流按实际模型和输入方式定稿；独立只需剧本时不强行补充模型提示词。
