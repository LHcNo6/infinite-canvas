# 宠物搞笑短视频制作（30 秒内）

以用户的宠物图片和想法制作一条完整搞笑视频。只要文字时使用 `petComedyScript`，不操作画布。默认竖屏、约 20 秒、480p；明确要求优先，上限 30 秒。首版一次生成一条视频，不自动分段或合成。

## 模式和创作

开始时询问交互或自动模式，用户已选择则不重复问。自动模式先集中取得本次目标、时长、画幅、分辨率、声音、必要图片规格、图片与视频供应商和模型或有序候选、总调用上限（含重试）、每对象失败重试上限的明确授权。说明完整提示词在授权后形成，费用不可查询时算力消耗未知；跳过、取消或未回答不授权。后续只在该范围内规划与执行；每次尝试计入总次数，先确保剩余次数足够完成所有计划初次调用。预算和重试余量不授权失败后直接重生成。

通过 `skillOperator(action=list)` 查找实际 `petComedyScript`、`videoPromptAdapter` 及 scope，再读取各自主文件；没有该工具时按本轮实际技能目录读取，无法读取则暂停依赖的步骤。将用户意图、可访问宠物图、时长和模型能力传给创作技能。按实际模型和输入模式由适配器定稿，包括 Seedance 2.5 的非带货搞笑短片路径。模型未确定时可以先形成暂定故事，实际模型确定后、生成前完成定稿。保留用户剧情、宠物身份、声音和真实参考职责，不套用商品或主播模板。

## 画布和生成方案

读取当前画布和可用节点类型，创建文本、图片生成“宠物主角”、图片生成“场景”和视频生成节点，避免遮挡已有内容。先用 `getNodeTools` 查询实际函数及参数，分别用 `node:setText` 和 `node:setPrompt` 写入剧情和提示词；不将文本节点连接到生成节点，以免提示词被追加。图片节点支持用户上传；没有导入工具时使用节点上传入口，不伪造接口或改画布 JSON。用户提供或选定的真实宠物图片优先复用；尚未上传时请用户上传并等待，不能凭文件名假装图片已就绪。已有可用输出不重新生图。场景节点仅在故事需要独立场景参考时启用，未启用不连接或生成；不创建商品节点。

用 `node:getConfig` 按实际 schema 查询节点、模型目录和视频 `matchingModes`，明确宠物图是首帧还是身份参考，选择可接收所有实际素材的模式；不得将身份参考冒充硬首帧或猜引用。设置并读回画幅、时长和分辨率，视频时长等于最终剧本时长，核对 `durationResolutionMap` 与实际输入。所选模型或模式不支持所需参考、时长或分辨率时保留画布并说明，请用户选择支持的方案；不静默换模型、缩短或丢弃参考。效果未知不等于不支持，记录尚需验收。核对实际声音设置；不静默改为无声或旁白。

交互模式在任何媒体生成前一次展示每个待生成对象、次数、模型和规格、完整提示词、真实或待生成的指定节点参考及用途、声音和视频时长，说明可得费用或算力消耗未知；取得明确同意才执行。自动模式记录同一方案并核对开头授权；用户修改模型、素材、规格或提示词时重新核对范围和依赖，超出或不明时暂停。生成前后都以真实连接和 `referenceOrder` 映射 `{{ref N}}`，不得猜编号。

## 执行和交付

按实际节点工具启动已授权、必要且缺失的图片，保存 `attemptId` 和 `startedAt`，调用 `node:waitGeneration({attemptId})`；图片就绪后核对本次输出、连接、配置和参考，再启动一次视频生成并等待该次终态。`waitBudgetExceeded`、运行中、取消和状态未知不代表失败，不重复生成；稍后先查询原尝试。旧输出和 idle 不代表本次成功。页面须保持打开，关闭或切换后不保证续跑。

明确失败时保留成果并暂停依赖链，按画布工具失败恢复流程提供手动查看调用记录和重新下载，或授权 Agent 查看本次记录并尝试一次下载恢复的选择。恢复不生成、不自动采用；下载成功请用户点击“使用结果”并核对。后续新生成须另获针对失败对象的明确授权，自动模式还须满足总次数、对象重试余量和其他对象的初次调用预算。跳过、取消或无回答不授权。

可用时生成前对目标节点调用 `preflightCanvas`，按工具约定维护 `getProduction`、`updateProduction` 和 `verifyProduction` 的清单及 revision；批量覆盖已有内容前用 `createCanvasSnapshot`，失败则停止覆盖。工具缺失时说明限制。报告视频节点及实际路径，区分生成成功、已检查和用户采用；未看或未听的内容如实说明。重开或继续时先读取画布和原尝试状态，不重复创建或调用。
