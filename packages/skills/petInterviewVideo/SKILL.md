# 宠物采访短视频制作

让采访过程中发生一件事：围绕一个核心命题，记者追问，宠物通过讲话、自然反应或选择改变局面，结尾回应开头。不要只给一句包袱、互不相关的问答或用频繁切镜填满时长。默认一只宠物、一个主要采访场景、中文对白、30 秒、9:16、480p；用户指定优先，首版上限 30 秒，实际模型能力决定可执行规格。

## 先辨别本次交付

- 只要主题、剧本、分镜或提示词：读取相应创作资料，只交付所需文字，不询问生成模式、不创建节点、不生成媒体。只要提示词才需要按实际目标模型读取适配器；目标未定时明确是通用草稿。
- 要制作视频：沿用已确认的主题、素材和原文，开始时确定交互或自动模式，用户已选则不重复问；按下方范围创作和执行。
- 已有主题或定稿不重启候选；只修改用户要求的内容。明确带货用对应带货流程，普通宠物单人口播用讲段子流程；超过 30 秒的完整视频交回长视频流程，不自行拆段。

## 读取真正安装的导演技能

通过 `skillOperator(action=list)` 查询 `aiPetShortVideoDirector` 的实际 name 和 scope，读取其主文件；生成主题或故事前，以同一 name、scope 读取 `path=references/story.md`，安排表演、分镜和声音时读取 `path=references/direction.md`。准备生成方案时按该技能入口读取 `references/generation.md`，审片时读取 `references/review.md`。无 skillOperator 时使用本轮技能目录的实际位置及可用 read 工具，不使用源码路径或本机绝对路径充当安装位置。

把用户意图、已知身份与性格、真实素材、交付阶段、时长、声音、模型已知限制与授权范围交给导演方法。导演只返回创作成果，不执行节点、不调用本技能回来；本技能负责下游执行。必需导演正文或资料不可读取时说明具体缺项，保留可独立交付的用户定稿与成果，暂停依赖的选题/导演步骤，不假称已调用或绕过停用状态。

新创作采访时必须读取本技能的 [三套完整示例](references/interviewExamples.md)。示例为虚构教学情节，不是用户宠物的真实习惯或已验证成片；借鉴其推进机制，不固定套用同一结尾。

## 从主题到完整采访

1. 区分可见身份、用户提供的习惯和创作提议。宠物图片不可读时不假称看过；只有制作依赖实际照片时才等待上传。只要主题或剧本时可基于明确标注的假设先创作，不把缺图变成不必要的阻碍。
2. 用户未指定主题时，使用导演故事方法提出三个机制不同的候选，每个包含核心命题、开头、宠物立场、中段变化、结尾回扣、个性化位置和主要难点，推荐一个。只要主题到此交付；要完整剧本或视频时直接展开推荐项，除非用户要求先选择，不额外添加选题确认轮次。已有主题或原文时只展开它。
3. 完整故事通常有四至六个叙事变化：开头建立疑问、问答建立立场、追问或事件带来证据、宠物作出反应或选择、结尾回扣，并留反应时间。按内容调整，不机械固定镜头数。每个重要段落都要增加信息或改变局面；无关追问、复述画面和填时长的停顿应删掉。
4. 记者默认在画外提问，宠物在画内说话，可有话筒入画，不默认出现记者面孔。两种声音清楚分离，不相互抢台词。主人声音只在故事确实需要时增加，单列为第三位说话者。讲话拟人化但身体保留动物结构，不默认人形站立、手势或手持工具。
5. 为每段写刺激、耳朵/视线/头部/身体的反应、必要动作和终态，再安排镜头及声音。允许笑点由画面证据完成，不强求只听对白就知道全部笑点。给说话、动作和结尾停顿真实时间，不把长台词硬塞进短时段；时间区间是目标而非模型精确执行的保证。
6. 单独检查：开头的问题是否值得等答案，中段是否真的改变理解，证据是否出现在画面或声音中，反应是否属于这只宠物，结尾是否回应开头。内容好笑、像自家宠物或能留住观众均须实际反馈，不能预先保证。

例：《它说自己不黏人》先让猫要求保持高冷，再用记者追问、钥匙声引起的身体反应、主人招呼后的撒娇逐步拆穿，最后要求删掉录像；完整时间表、逐字对白和替换位置见示例文件。其他示例分别展示现场验证后重新解释，以及记者在采访中被宠物“训练”。

完整剧本交付标题、采访命题、时长和画幅、身份与性格依据、候选推荐理由（适用时）、可独立查看的逐字对白、按时间排列的事件/说话者/表演/必要镜头/声音、开头与结尾的关系、素材职责、主要生成风险和验收点。按用户要求控制深度，主题请求不强行交整套制作资料。

## 模型适配与画布

制作时通过实际目录读取 `videoPromptAdapter`，由其按确切模型、版本和输入模式定稿；Seedance 2.5 非带货采访也走此路径，不套用带货 Skill。模型未确定时可形成通用草稿；生成及交互模式具体方案授权前，实际模型必须确定并完成适配。保留采访剧情、逐字对白、声音归属、身份与真实参考职责，缺少模型表现证据时标记未验证，不自行改成旁白或无声。

已安装的旧版适配器可能没有 Seedance 2.5 非带货采访的专篇路由。仅当实际目标确为 Seedance 2.5，且读取到的适配器未覆盖非带货采访时，按其第三方路由要求从实际全局技能目录查找 `videoPrompting`，以返回的 name 和 scope 读取主文件、`sourceInfo.md` 和 `references/models/seedance25/prompting.md`，将适用规则与来源交给适配器定稿，并核对成稿保留双方逐字台词、采访顺序、真实参考和声音职责。无 skillOperator 时使用实际技能目录及可用读取工具。匹配资料确实不可读取或不覆盖该模式时使用通用方法并明确标记该模型专门优化未核实；不假称读取成功，不覆盖已安装的用户适配器，不因此静默换模型或删声音。其他模型继续使用适配器针对其确切版本和模式的路由，不读取 Seedance 2.5 专篇。

读取当前画布与可用节点类型，复用本次已有节点与可用输出；需要新建时创建文本、图片生成“宠物主角”和视频生成节点，独立场景参考确有需要时再建图片生成“采访场景”。不创建商品节点，不把文本节点连接到生成节点，避免脚本追加进提示词。先用 `getNodeTools` 查询真实函数和参数，再写入剧本、资产提示词和完整视频提示词。

用户照片优先作为真实身份或起始图，按模型模式分配，不强制重新生成标准主角图；图片节点有上传入口，无导入工具时等待用户上传，不伪造导入接口。场景参考需要单独生成时说明是否包含宠物及其职责，避免多张图中的重复宠物被理解为多个角色。

用 `node:getConfig` 按实际 schema 查询模型目录、当前配置和 `durationResolutionMap`；模型清单需要 `includeModels` 时按该节点支持的 schema 显式获取。生成图片前先根据模型声明和计划素材的类型、数量、身份参考或硬首帧职责、画幅、时长、分辨率及声音确定可行方案。待生成图片还没有真实输出时，`matchingModes` 不能用于排除计划中的图生视频模式：授权方案列出指定资产节点及用途，待输出后再完成连线和模式设置。

素材就绪后通过 `getCanvasNodes` 读取两端真实端口，用 `connectNodes` 批量连接宠物图片及启用的场景图片输出到视频输入；复用已有适用的真实输出，勿连接文本或未启用的场景。读回边、上游输出和引用顺序，再查询视频节点实际 `matchingModes`，按真实 schema 设置画幅、最终剧本时长、分辨率、模式及声音并读回。按真实连接与 `referenceOrder` 映射 `{{ref N}}`，不猜编号。模型声明明确不支持计划、素材就绪后的真实模式不匹配或必要条件不支持时保留成果并请用户选择，不静默换模型、删声音、缩短故事或增加分段。

首版单次生成一条完整采访视频，不自动分段、合成、后期配音或加字幕。导演建议拆分时先减少不影响故事的动作；仍无法承载则说明代价并交用户选择，不为守住单次生成而删除关键因果。模型能否准确执行多说话者、台词、口型、分镜和时间尚需实片验证；不依赖画面生成的文字来表达关键线索。

## 生成范围与执行

交互模式在媒体生成前一次展示本批对象和数量、模型、规格与时长、完整提示词、真实或待生成的指定节点参考及用途、记者/宠物/可选主人声音、执行次数、可得费用或“算力消耗未知”；明确同意后按范围执行。

自动模式开始时集中明确目标、必要图片规格、视频时长/画幅/分辨率/声音、图片与视频供应商和模型或有序候选、总生成调用上限（含重试）和每对象失败重试上限。说明完整提示词在授权后形成、报价不可得时算力消耗未知，取得对该范围和自动生成的明确同意。自动模式在范围内记录完整方案并核对执行，不再逐主题、剧本或提示词询问。跳过、取消或未回答不授权；预算指引不是程序级强制保护。

调用前核对实际模型、提示词、素材、规格及余量，保留完成其他计划对象初次调用的次数。用户修改内容、模型或素材时重新核对受影响范围，超出或不明则暂停。只启动已授权且缺失的必要图片，记录 `attemptId`、`startedAt`，用 `node:waitGeneration({attemptId})` 等待；素材就绪后按上述步骤连线并核对实际输出、`matchingModes`、配置和参考，再启动一次视频生成并等待该次终态。已存在的旧输出和 idle 不证明本次成功。运行中、等待超时、取消或状态未知不重复生成；重开先读原尝试，页面关闭或切换后不保证续跑。

明确失败时保留成果，按宿主流程提供手动查看调用记录和重新下载，或授权 Agent 查看本次记录并尝试一次下载恢复的选择；恢复不生成、不自动采用。下载成功由用户点击“使用结果”并核对。失败后的新生成另获针对该失败对象的明确授权，自动模式还需满足总预算、对象余量和其他初次调用预算；不能凭重试余量直接重生成。

有工具时沿用 `preflightCanvas`、`getProduction`、`updateProduction`、`verifyProduction` 的清单和 revision；批量覆盖前用 `createCanvasSnapshot`，失败停止覆盖。工具缺失如实说明，不另建重复导演收据。

## 采访成片验收

按导演审阅方法实际观看并听取完整输出，核对宠物身份、动物结构、记者与宠物是否串台、是否读错对方的问题、可选主人声音是否归属正确、逐字台词、口型、事件顺序、中段证据、关键反应、结尾回扣与停顿。导演的修订建议不等于授权重生成。

报告真实视频节点与路径，区分生成成功、实际已检查和用户采用；没有看或没有听的内容如实列明，不能以提示词、文件存在或技术播放成功替代内容验收。
