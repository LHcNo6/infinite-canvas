# 采访逐镜预算与详细定稿

写完整分镜、生成提示词或修订节奏时读取。先用本技能入口的时长规则完成预算，再把分镜交给实际模型适配器；本文件示例是假设创作，未经生成验证。示例中文不改变用户所选语言。

## 完成标准

1. **内容**：每次追问都推进立场、证据或选择。短句先合成同镜问答，仍显空时在允许创作的范围补充有效信息；用户逐字定稿保持原文。默认上限不是目标时长。
2. **预算**：逐镜列出每句说话估时、换气/接话、同步动作、单独占时动作和余量用途。先按自然朗读安排，不先画出六个五秒格再往里面放句子。4 秒可以说两句短话，足够长的一句也可以独占；以自然时长判断，不机械数句子。
3. **表演**：每镜写清机位/景别与空间、刺激、耳朵/目光/身体如何响应、动作过程和结果、各句说话者及语气、台词与动作同步关系、切镜交接状态。静态机位可以持续使用，终态可以发生在切点，无须另留展示时间。
4. **定稿**：实际读取导演、适配器及匹配模型专篇，把完整分镜和预算交给适配器，生成完整可提交正文。读回视频节点的全文，逐镜对照；剧情、逐字台词、说话顺序、同步动作和关键证据全部保留后，才可交付定稿或申请生成授权。记录实际来源，缺失依入口回退，不声称已经优化。

## 失效模式

“0–5 秒记者问一句；5–10 秒宠物回答一句”会要求模型直到第五秒才接答。即使前三秒已问完，剩余两秒也被安排成等待。把“说完闭嘴，保持到下一镜”写进每个镜头，会把说话者归属误变成独立表演任务。

修订应把短问答放在同镜，明确问完自然接答、倾听反应与提问同步，并按内容预算；仅在开头加“快节奏”、末尾加“时间为目标”，或堆叠毛发、光影形容词，都没有解决台词与时长的失配。

## 16 秒完整示例：它把遛弯说成加班

**假设**：允许代写，单只柴犬阿柴、室内门厅、蓝色项圈；采访者只有画外声音和同侧话筒。用户已提供宠物身份图，牵引绳作为虚构故事道具从开场就在右侧地面。真实模型须支持 16 秒、有声和相应图片参考模式；本例不证明该组合可用。若不支持，在授权前重新预算可行方案。

**完整对白**：记者“阿柴，今天忙什么？”阿柴“巡逻，整个小区归我管。”记者“那家里谁管？”阿柴“小地方，配不上我这身本事。”记者“这是巡逻，还是想遛弯？”阿柴“顺便，顺便。”记者“一圈够吗？”阿柴“两圈起步！我还能再加班。”

| 镜头 | 逐句自然说话预算（中文约 4.5 字/秒初估） | 动作、接话与余量 |
| --- | --- | --- |
| 0–4 秒 | 记者约 1.6 秒；阿柴约 2 秒 | 约 0.2–0.3 秒换气；挺胸和看话筒与对白同步，其余为自然发音弹性 |
| 4–8 秒 | 记者约 1.1 秒；阿柴约 2.4 秒 | 约 0.2–0.3 秒接话；听问时看绳，回答时已起身迈近一步，动作不断开计时 |
| 8–12 秒 | 记者约 2 秒；阿柴约 0.9 秒 | 约 0.2–0.3 秒接话；记者提问期间完成低头轻触绳子的证据，回答时抬眼回看，余量用于这次心虚的视线变化 |
| 12–16 秒 | 记者约 0.9 秒；阿柴约 2.4 秒 | 约 0.2–0.3 秒接话；尾巴和前倾同步，回答中主动看门完成回扣，结束不再静止拖尾 |

预算包含自然语气，不是配音秒数证明。实际朗读超时先调整镜长或在允许范围改写，不吞字；已有音轨以真实时长为准。

写实轻喜剧宠物采访：阿柴一本正经自称巡逻员，现场动作揭晓它其实想出门多遛两圈。对白清楚、自然接续，身体动作按正常速度发生。

参考职责：{{ref N}} 为已核实的柴犬身份图，控制同一只狗的脸、毛色和蓝色项圈；此图作为身份参考，不假定是硬首帧。一个温暖明亮的室内门厅，左侧窗光柔和稳定。柴犬起初坐在画面左半部，松盘的牵引绳始终在它右前方地面，门在画面右侧背景；话筒从左边缘进入并保持同一来源方向。全片只有一只狗，保留真实犬类口鼻、前爪、四肢和身体结构。

镜头1【0–4秒】：平视中景，狗、右前方的绳子和背景门同时可见。话筒开场已就位。记者画外清楚提问：“阿柴，今天忙什么？”阿柴听到“忙什么”时耳朵前转、胸口微抬，目光跟着话筒；问完自然换气便认真回答：“巡逻，整个小区归我管。”挺胸与回答同步，不等切镜才开口。回答结束时视线略转向右侧，接入下一问。

镜头2【4–8秒】：维持同侧平视中景和绳子的空间位置，接住上一镜向右的视线。记者画外追问：“那家里谁管？”阿柴在听问时已把注意力转到牵引绳，自信接答：“小地方，配不上我这身本事。”说话同时由坐姿起身，向右前方迈近一步；重心自然转移，四肢保持犬类结构。切点时它正到绳子旁，不坐回原位，不增加无对白的起身展示。

镜头3【8–12秒】：略近的平视中景，接住阿柴到达绳旁的动作，头、口鼻、前爪和绳子都能看清。记者画外立刻问：“这是巡逻，还是想遛弯？”阿柴听问时闭嘴，低头让鼻尖轻触地上的绳子一次，绳子留在原处；记者说到“遛弯”时，它抬眼看回左侧话筒，心虚又轻快地接答：“顺便，顺便。”视线已朝门偏去，证据和接话在本镜内完成，不另留发呆时间。

镜头4【12–16秒】：同侧中景接住朝门的视线，阿柴站在原绳旁，话筒从左侧稍跟近。记者画外问：“一圈够吗？”阿柴立即把目光转回话筒，语气突然积极：“两圈起步！我还能再加班。”回答时尾巴小幅摆动，身体朝右侧门轻轻前倾，末句中再次看门，完成想出门的回扣。话说完、短促眼神反应完成即结束，不再保持到额外空白尾段。

声音：记者是温和清晰的画外声，阿柴是明亮认真、逐渐露出兴奋的画内声，两种音色跨镜一致；轮流说话不重叠。狗仅在自己的台词时自然开合嘴部，听问时仍有同步视线和身体反应。轻微室内环境声、爪子落地轻响；无背景音乐、字幕、其他动物或多余人声。镜头区间是叙事预算，须通过实际成片核验。
