# 宠物主播逐镜写法与示例

## 逐镜编排

先写真实商品信息、完整口播和必要演示，再按内容组织每镜至少 4 秒的分镜。一镜可有多句台词、完整问答或同步动作；先合并内容过少的短句，再在允许创作范围补充有效信息。中文口播约 4–5 字/秒只是初估，已有音频用实际时长。4 秒镜头约 14–18 字是复核参考，不把商品事实、台词或动作凑成配额。

| 内容 | 需要写清的内容 |
| --- | --- |
| 展示目的 | 本镜新增的事实、演示证据或宠物态度，以及下一镜继续揭示什么 |
| 表演与接触 | 姿态、视线、前爪落点、商品位置，接触方向、主动作及可见结果 |
| 时间 | 连续时间区间、口播与必要动作预算；同步的简单动作和说话只计一次 |
| 取景 | 看清口鼻、接触和效果所需的景别、机位、焦点及光线，不强制运镜 |
| 声音 | 真实说话者、逐字台词、自然语气、必要接触声和有作用的短反应 |
| 衔接 | 接续正在发生的动作、视线或商品状态；终态用于连续性，不另加静止保持 |

口播可与简单示意、观察和安全的单次接触同步；动作太复杂时先简化非关键部分或重新分配内容。嘴部跟随自己的台词，非自己说话时闭嘴，句子自然接续。无对白的商品演示只有持续提供新观察时才单独占一镜；不要把逐渐停稳或收爪归位单独拉成数秒。

全片身份、商品事实、光线与声音约束集中写；各镜只写变化和必要锚点。镜头区间连续，最终总时长等于各镜之和；固定用户时长、逐字原文或模型能力冲突时交回工作流，不擅自改定稿。参考尚未就绪时写资产职责和绑定规则，不凭示例编号假称已经绑定。

## 完整示例：一次轻推看清玩具

以下为未实测的虚构教学例。假设用户提供宠物照片、玩具实图和桌面场景，已确认轻推会摇晃，允许代写中文口播，不加背景音乐。只说这项已知事实，不补造材料、价格、性能或购买入口。计划 12 秒、9:16，须由实际节点支持。

| 分镜 | 有效信息与动作 | 逐字口播 |
| --- | --- | --- |
| 0–4 秒 | 猫看镜头介绍，前爪同时示意右侧玩具；视线随即转向玩具 | “今天轮到本喵当主播，给你看个会摇的玩具。” |
| 4–8 秒 | 接视线切到接触面，前爪轻推一次并收离，观众立即看见摇晃 | “轻轻推这一下，你看，它就在桌上摇起来了。” |
| 8–12 秒 | 接续玩具余摆，爪子清楚留在旁边，猫边观察边看回镜头 | “刚才只推了一次，后面可没有偷偷再碰它。” |

**资产**：宠物和商品实图直接复用；场景只在需要时补充，不能带入第二只宠物。以下假设引用顺序为宠物、玩具、场景，提交前须映射真实输入。

**完整视频提示词**：

~~~text
一只橘猫模仿主播介绍桌上的猫玩具，中文口播轻快清楚，动作以正常速度连续发生。
参考职责：{{ref 1}} 控制猫咪身份与外观，保留自然猫口鼻和前爪；{{ref 2}} 控制玩具形状、颜色、比例及部件；{{ref 3}} 控制桌面布局和光线。全片同一只猫和一个玩具，猫在左侧、玩具在右侧，主光来自左侧。

镜头1【0–4秒】：平视中近景，猫和完整玩具同框。猫直接看镜头，用左前爪朝玩具示意，边说：“今天轮到本喵当主播，给你看个会摇的玩具。”目光随台词转向玩具，前爪开始接近它，动作顺接下一镜。

镜头2【4–8秒】：切到能看清前爪和玩具底部的中景，承接前爪接近的动作。左前爪触碰玩具中部，向右轻推一次后离开，玩具底部仍接触桌面并开始左右摇晃。猫同时说：“轻轻推这一下，你看，它就在桌上摇起来了。”切镜时玩具仍在摇，爪子已经离开。

镜头3【8–12秒】：接玩具正在摇晃的状态，猫和玩具同框，左前爪在桌上清楚可见。猫看玩具再看镜头，连贯地说：“刚才只推了一次，后面可没有偷偷再碰它。”玩具保留自然余摆，猫完成台词和一个短促得意眼神后结束，不另等玩具停稳或保持结尾姿势。

声音：猫是唯一说话者，跨镜音色一致，嘴部随自己的中文台词开合，句间自然衔接；保留轻微室内环境声和实际接触声，无背景音乐、无额外说话者。
~~~

**验收**：三镜各 4 秒、口播自然、每镜有新信息；接触后才摇晃且只推动一次；跨镜余摆与爪子位置连续；没有句末空等、重复演示或停稳等待。时间边界是创作预算，需实际看听；台词说不完时延长相关镜头或在允许范围精简，不靠加速吞字。
