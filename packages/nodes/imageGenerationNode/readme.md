# 图片生成节点

根据提示词生成图片，也可使用已有图片和文本作为参考，制作角色、场景或分镜图。

## 输入与输出

- 输入支持图片和文本；连接的文本会作为生成要求的一部分。
- 输出一张生成图片，可继续用作图片或视频生成的参考。
- 空节点可直接上传图片作为当前输出；选中已有图片的节点后可从顶部替换图片。

## 使用方法

1. 选中节点，在下方选择图片模型；没有模型时先在设置中添加图片模型。
2. 输入画面要求，按需连接图片或文本参考，并在提示词中引用它们。
3. 点击比例与分辨率区域，选择当前模型提供的选项。
4. 点击“生成图片”；生成过程中可点击“停止生成”。
5. 完成后在节点内查看结果，选中节点可从上方下载或放大预览。

参考素材可在输入区调整顺序或移除。连接的节点需要已有内容，修改提示词或设置后需再次点击生成才会产生新图片。

## Agent 调用记录与下载恢复

通过画布工具 `getNodeTools` 查询本节点的实际函数后，可使用：

- `node:getModelCalls`：读取合并后的磁盘与旧画布记录；`callId` 查询单条详情，`offset`、`limit` 分页，默认 10 条、最多 50 条。
- `node:retryDownload`：按 `callId` 重新下载已生成的成品。`canDownload` 为 true 时直接恢复；`canSupplyResult` 为 true 时可传用户提供的 HTTP(S) 成品直链 `url`。不会重新生成或替换当前输出，需在“调用记录与恢复”窗口点击“使用结果”。

工具返回调用状态、错误、结果路径和可恢复能力，不返回内部恢复地址；详情中的网址隐藏。取消或超过节点工具的 120 秒等待上限，不代表后端下载已停止，应先重读记录，不能自动重复下载或重新生成。只有旧画布记录、没有独立记录时不能恢复；没有地址时须由用户提供原成品链接。
