# 制作检查、清单与关键版本

[返回知识库](readme.md)

## 入口与边界

Web 画布右上角「制作与版本」包含生成前检查、制作清单、关键版本。Agent 使用同一组画布工具；仍由当前打开的画布执行，不新增调度服务或自动续跑。

## 生成前检查

`preflightCanvas({ nodeIds? })` 省略节点时检查选中节点；没有选择时检查全部内置图片、视频生成节点。返回逐节点阻塞、等待依赖、提醒或未完成检查。不支持该能力的节点明确返回未知，不算通过；检查期间画布变化会使结果失效。

节点通过 `node:preflightGeneration` 暴露相同检查；实际生成提交前再次执行。覆盖提示词、模型目录与有效规格、引用就绪及本地文件存在、忙碌状态和视频首帧/衔接绑定。衔接参考继续核对既有来源与文件摘要。检查不会提交生成、报价或证明画质，通过也不替代生成授权。插件内部提示保留插件原文。

## 制作清单

清单存为 `.toonflow/productions/<UUID>.json`。`getProduction` 读取或列出当前画布的清单；`updateProduction` 新建或完整更新，最多 100 个稳定 ID 步骤。更新已有记录必须携带 `revision`，沿用工作区文件的条件原子写入；冲突不会覆盖新内容，面板保留未写入草稿。

步骤的 `status` 是计划状态，可关联 `nodeId`、`attemptId`、`resultPath`，并记录备注和 `usedDownstream`。计划完成、生成核验、已用于下游和人工审阅分别展示。Agent 不能通过更新计划将人工审阅设为采用。

`verifyProduction` 重读独立媒体调用记录，核对节点、尝试 ID、结果归属及文件可读性。成功只表示此次调用成功且文件可读；历史运行记录若无法对应当前页面仍持有的任务，则标为未知。节点/尝试/结果未关联不会推断成功；所有核验均不重新生成。核验结果只用于本次展示，刷新后须重验。

用户在核验成功后可确认采用；写入前再次核验并检查清单版本。更换节点、尝试或结果路径会清除旧采用记录。采用是用户决定，不是 Agent 审片证明。文本或合成步骤可记录计划，本版自动成果核验只覆盖具有独立媒体调用记录的图片/视频生成。

关闭或切换清单时询问是否放弃未保存编辑。切换画布/工作区前应保存清单；刷新不会保存尚未提交的草稿。画布改名/移动时同步清单路径，失败则尝试回退本次改名和关联更新，回退遇到冲突不会覆盖并发内容。

## 关键版本

`createCanvasSnapshot({ name })` 先保存当前画布，再复制数据、节点素材目录和公开字段引用的本地文件到 `.toonflow/canvasSnapshots/<UUID>/`。逐文件核对 SHA-256，完成前复核源文件和画布 revision；清单最后独占发布，未完成目录不显示为可恢复版本。

`listCanvasSnapshots` 列出工作区版本。`restoreCanvasSnapshot({ snapshotId, name })` 校验版本结构、节点/边/父子关系、插件可用性及素材摘要，恢复为根目录的新画布和独立素材，拒绝同名覆盖。节点、边、提示词引用、引用顺序及合成片段来源一起重映射，旧生成调用身份清除。原画布及原素材保留，不切换、不重新生成。

首帧和衔接绑定不沿用旧生成身份；恢复后标记需要重新核对并阻止直接提交，通过节点配置重新绑定或明确清除。旧尾帧仍可作为普通图片查看，但不能假冒新画布生成的尾帧来源。

外部网址未复制；其他插件的私有状态仅按画布数据、节点目录及公开文件引用保留，不保证完整恢复。版本须随工作区一起备份；没有版本自动清理、增量压缩、自动快照或供应商任务恢复。大素材逐文件复制和摘要，内存及耗时取决于单个文件大小，尚未做大规模性能验收。

## 实现入口

- `packages/nodeShared/src/useGenerationPreflight.ts` 及图片、视频生成插件：节点检查与提交复用。
- `apps/web/src/pages/workspace/panels/canvas/canvasProduction.ts`：版本、独立素材、清单条件写入及关联移动。
- 同目录 `useCanvasProduction.ts`、`components/productionPanel.vue`：工具执行、状态核验及人工入口。
- `packages/tools/canvas/src/runtime.ts`：七个工具的参数与描述。
- `packages/skills/{canvas,workflow,longVideoWorkflow,petShortVideo}`：新结构化任务不双写相同 Markdown 台账，旧台账不自动迁移。
