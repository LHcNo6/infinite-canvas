# 项目名称避免误编辑

日期：2026-11-18

画布左上角项目名称与箭头组成切换按钮，使用下拉菜单中的“重命名”进入输入模式；回车或失焦保存并退出，Esc 撤销并退出。名称中的空格仍然允许，已有名称不会被自动改写。

此前名称始终是输入框，单击即可获得焦点，回车保存后焦点仍保留。浏览器复现确认此时空格会进入名称；截图中的名称实际包含空格，但其具体输入经过无法确认。实现位于 `apps/web/src/pages/workspace/panels/canvas/components/canvasMenu.vue`，相关行为见[工作区切换](../workspaceSwitch.md)。

验证：Ego Lite 中确认悬停为手形且不进入编辑、点击按钮打开菜单、菜单中的编辑项聚焦、Esc 撤销；之前也确认回车退出后空格不再写入。Web 类型检查和构建通过，开发页面和构建服务返回 HTTP 200。开发服务属于其他 Codex 会话，未重启，页面通过热更新验证。未验证其他浏览器、输入法组合和长名称的全部显示场景。
