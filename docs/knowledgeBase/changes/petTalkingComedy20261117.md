# 宠物拟人讲段子工作流

日期：2026-11-17

根据用户对原宠物搞笑剧情成片笑点不清晰的反馈，将 `petComedyScript` 和 `petComedyVideo` 改为宠物拟人讲段子，保留技术名称，版本均升至 1.1.0。默认先创作可独立听懂、具有铺垫和包袱的中文画内口播，再用简单表情、视线和停顿配合；用户原文、宠物身份和明确的形式要求优先。未指定形式的宠物搞笑需求默认走此方向；明确其他剧情形式或带货时按用户意图分流。仅文字请求不生成媒体。

中英文技能位于 `packages/skills/petComedyScript/`、`packages/skills/petComedyVideo/`；服务端分流位于 `apps/server/src/agent/runtime/prompt.ts`。`videoPromptAdapter` 在本机验证时为 1.1.5，合入采访功能后调整为 1.1.7，同步 Seedance 2.5 非带货适配描述，既有模型适配、实际参考、授权、等待和失败恢复边界保留。详情见[宠物短视频维护说明](../petShortVideo.md)和[技能语言维护说明](../skillLanguages.md)。

验证：Bun 1.4.0（项目声明 1.4.3）下服务端类型检查与构建通过；构建及数据目录的六个中英文技能文件与源码一致。服务端重新启动，网页 `http://localhost:5173` 返回 HTTP 200，技能接口返回两项 1.1.0 和适配器 1.1.5，均启用且标记为内置；`git diff --check` 通过。原服务在检查时已不再监听 3000，原因未确认；Web 服务保持运行。安装副本在同步前与原源码一致，其他环境的同名已安装版本不会自动覆盖，需要按正常更新流程处理。

未运行真实 Agent 路由、画布操作或付费生成；没有观看、听取新成片，也未验证笑点、中文台词准确性、口型和停顿。提示词是行为指引，不保证模型遵循或段子效果。回滚可恢复这两个技能及路由的旧版本并保留适配器中的采访能力，并谨慎更新已安装副本；无数据迁移。
