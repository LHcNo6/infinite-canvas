# 短句同镜、逐镜预算与定稿复核

日期：2026-11-17。

## 问题与已核实原因

本地最新宠物采访生成前的节点提示词，把六句共 47 个汉字分成 30 秒的六个时间块，包含短问句独占五秒、说完维持姿势、停一拍和停留到结束。已有“按内容规划、短问答可同镜、删除无效等待”规则未体现在该方案中。

本地会话记录显示：上一条采访在北京时间 15:17 读取 `petInterviewVideo` 1.0.0、导演资料和 `videoPromptAdapter` 1.1.6，15:20 读取第三方 Seedance 2.5 专篇；节奏修订版安装文件在 16:16 更新，最新采访在 16:26 只重新查询目录，没有重新读取入口和资料，16:28 启动生成。旧上下文复用是已核实的执行遗漏；不能据历史阅读宣称本次完成了重新适配，也不能从缺少工具调用证明模型完全没有在内部整理文字。

生成前 `node:setPrompt` 与调用前节点读回内容一致；模型调用记录显示本次成功，文件实长 30.08 秒、480×854、含音频。未取得供应商不可变请求正文，不将可编辑画布单独当作提交快照。FFmpeg 以 -35 dB、至少 0.5 秒检测，3.35–5.54 秒约有 2.20 秒低音量区间，21.89–26.24 秒约有 4.35 秒；抽看六帧可见坐姿、看绳、起身和靠近绳子的变化。低音量与抽帧只能辅助定位，本次没有完整听审或逐帧验收，不能把检测值直接当成精确接话间隔或自动裁剪依据。

## 实际改变

- 四组创作技能把“可以多句”补强为短句优先同镜两句/多句或完整问答。对白主导的 4–6 秒镜头，单句须有足够自然说话时长；纯动作证据另按必要变化预算，闭嘴、转耳和保持姿势不用于填时长。
- 创作方交付逐镜预算：每句自然说话估时、接话/换气、同步动作、单独占时动作及余量用途。普通接话以约 0.2–0.5 秒自然换气为目标，无对白超过约 0.5 秒需说明有效信息或证据作用。数字为规划/审片参照，不承诺模型精度、不机械凑字、不抢话或加速原音频。
- 宿主每次开始新视频或重新定稿，要求本轮重新读取创作/执行入口、所需阶段资料及定稿规则。同一任务本轮已读且适用的正文可复用，目录和上一条视频历史阅读不代替本次读取。
- 采访按“完整对白与预算 → 导演表演分镜 → 模型适配完整正文”完成；适配器保留机位/景别、空间、刺激与反应、动作过程/结果、逐字对白/语气/接话、同步及跨镜状态，缺失内容交回创作方。实际版本、专篇路径与回退记录留在已有方案，不进模型正文。
- 视频节点写入后读回全文，与预算及分镜逐项对照，缺失或空等先修订；技术 preflight 通过不替代创作复核。已有逐字定稿、固定时长、模型能力及生成授权不静默变更。
- 新增采访详细指南和 16 秒四镜的完整虚构示例，每镜有问答及同步表演；附预算、失效模式和实际来源记录的要求。未改写现有用户画布或成片。
