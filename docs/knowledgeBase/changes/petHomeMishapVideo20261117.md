# 宠物家庭小糗事与 SD 专用定稿

日期：2026-11-17。

## 功能与行为

新增 `petHomeMishapVideo` 1.0.0，为藏东西、拆家补救、叫醒主人等家庭小事件创作主题、完整剧情、分镜和提示词，或在画布制作不超过 30 秒的单条视频。默认单宠、一个主要场景、中文对白、9:16、480p，总长按有效内容预算。主人默认画外，必要时只露手脚；仅文字请求不询问生成模式、不操作画布或生成媒体。明确采访、单人口播、带货及长视频按对应流程处理。

核心结构为宠物目标、行动、阻碍、改变方法、意外结果和结尾回扣。三套虚构教学故事分别展示藏鞋被球引开后交换失败、纸卷越收拾越乱、叫醒主人却自己被摸睡，含完整对白、逐镜预算和详细模型定稿写法，分别为 21、17、16 秒。示例未经跨技能执行或实际生成；示例时长及声音/动作要求必须核对实际节点能力。

创作由 `aiPetShortVideoDirector` 提供故事与表演方法，Seedance 2.5 的最终提示词必须使用实际全局安装的 `sd25-pe`，其他实际模型使用 `videoPromptAdapter`。SD 定稿后工作流逐镜核对，不再交通用适配器重写；没有增加新的模型、工具、服务、配置字段、数据库迁移或账号要求。本机原有 `sd25-pe` 继续保留，未执行其自更新、安装或媒体接口。

## 节奏与定稿约束

- 每条新视频/重新定稿在本轮重新读取工作流、当前阶段导演资料与模型定稿正文；目录查询、上一条的旧阅读和示例不作为本次优化完成的证据。
- 先完成对白与必要行动再预算镜头，每镜至少 4 秒，短句优先同镜多句/完整交流。逐镜列各句自然估时、换气、同步动作、单独占时动作、余量用途与跨镜状态。中文约 4–5 字/秒、普通接话约 0.2–0.5 秒仅为规划参照。
- 纯动作区间需有寻找、遮挡、补救、揭示或选择等可见变化；无对白超过约 0.5 秒说明其作用，不能自动删掉或用微表情、保持姿势填满。同步动作和对白不重复计时，回扣完成即结束。
- 用户及本流程的节奏要求优先于 SD 技能关于用慢动作/停顿适配更长外部目标的建议。内容不匹配返回创作阶段，固定时长与逐字定稿冲突交用户选择；不靠拖慢、复述或静默扩写解决。
- SD 保留已给定的整数秒创作时间与故事契约，参数外置，实际平台引用按真实连接绑定。缺必需正文或停用时保留导演稿、暂停专用定稿；SD 自更新服从宿主维护授权与写权限，默认使用可读本地版；未执行如实记为未更新，获准后的实际失败按上游提示继续本地版，不借联网命令绕过 skillOperator。
- 方案保留完整故事/对白、预算/详细分镜、最终正文、本轮真实来源 name/scope/版本字段和回退/未完成项。写入节点后读回全文，逐镜核对事件、逐字对白、声音归属、动物表演、关键道具和跨镜状态；技术 preflight 不替代内容复核。

这次是技能与宿主指令约束，不是程序级质量锁；不保证 Agent 必然正确遵循或模型准确执行。
