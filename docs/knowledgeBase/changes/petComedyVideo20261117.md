# 宠物搞笑短视频工作流

日期：2026-11-17

新增 `petComedyScript` 剧情技能与 `petComedyVideo` 单条视频制作技能，提供中英文入口。用户提供宠物图片后可创作并在授权范围内生成 30 秒以内的搞笑短片；不创建商品节点，场景参考按需启用。文本请求只产出创作内容。默认竖屏、约 20 秒、480p，模型能力与实际引用以节点为准；生成失败沿用恢复选择，不能凭重试预算直接重生成。

服务端路由及已初始化目录补装登记位于 `apps/server/src/agent/runtime/prompt.ts` 和 `apps/server/src/app.ts`；`videoPromptAdapter` 1.1.4 新增 Seedance 2.5 宠物搞笑短片的第三方专篇路由。详情见[宠物短视频维护说明](../petShortVideo.md)。新技能和适配器源码已同步到本机 `data/skills`、`build/skills`；同步前确认适配器两种入口与仓库原版一致，同名新技能目录不存在。其他环境中的既有适配器仍需按正常更新流程处理，不能假设启动会覆盖。

验证：服务端 TypeScript 类型检查通过；技能加载器从源码识别两个技能，因仓库规定使用小驼峰名称，加载器对它们和既有同类技能均报告命名警告，但仍返回技能。`git diff --check` 通过。当前环境找不到 Bun，服务端构建未完成；本机 3000 和 5173 端口未响应，无法验证重启、网页或服务接口。未进行真实 Agent 自动路由、画布交互、上传、付费生成、声音和成片质量验证；提示词约束不是程序级预算保护。
