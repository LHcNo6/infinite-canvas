# 宠物采访与 AI 宠物短视频导演

日期：2026-11-17。

新增 `petInterviewVideo` 1.0.0 和 `aiPetShortVideoDirector` 1.0.0，均提供中英文入口。采访技能从实际安装目录读取导演主文件及故事、表演、生成规划和审片资料，导演只提供创作方法，采访技能负责模型适配与画布执行，不循环调用。主题、剧本、分镜、提示词请求只交付文字；视频制作默认单宠、一个主要采访场景、30 秒、9:16、480p，实际节点能力及用户指定优先。未给主题时提供三个不同机制的候选并推荐展开，已有主题与定稿优先，不增加选题确认轮次。

采访包包含三套完整的虚构 30 秒示例：高冷采访露馅、安保涨工资的现场验证、记者被宠物训练。每套记录时间、画面事件、逐字对白、声音归属、个性化位置、因果回扣与主要生成风险。示例不代表已生成成片或用户宠物的真实习惯。采访以追问、证据、宠物反应及结尾回扣推进，不退回单句包袱或互不相关的问答。

导演来自用户指定的 Balance0014 `ai-pet-short-video-director` 1.0.0，以 MIT 许可适配为平台小驼峰名称。保留四份英文方法正文、完整许可和源入口 SHA-256，添加中英文入口与平台制作证据说明。未复制原包的检查脚本、评估文件、展示资产和安装说明，不引入 Python 或重复 JSON 收据。详情见 `packages/skills/aiPetShortVideoDirector/sourceInfo.md`；未独立核实来源包的远程仓库或上游提交。

- `packages/skills/petInterviewVideo/`：采访工作流及完整示例。记者默认画外、宠物画内说话，必要主人声音单列；真实照片优先复用，独立场景参考按需，不创建商品节点。首版一次生成完整视频，不自动分段、合成、后期配音或加字幕。

- `apps/server/src/app.ts`：已初始化数据目录缺失这两个技能时补装，已有同名目录不覆盖。
- `packages/skills/videoPromptAdapter/`：中英文同步更新至 1.1.6，Seedance 2.5 非带货采访通过对应第三方专篇或明确标记的通用回退定稿；保留多说话者、逐字对白、问答顺序、中段证据及结尾停顿。
