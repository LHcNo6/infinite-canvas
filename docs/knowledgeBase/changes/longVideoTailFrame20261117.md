# 长视频工作流按需提取尾帧

日期：2026-11-17

视频生成节点成功后不再自动提取尾帧；手动按钮和节点工具仍可提取。长视频工作流在每段成功后主动调用提取工具，等待并核对本次视频及 attemptId，再用于衔接。新生成仍清除旧尾帧记录，未启动提取时状态为 idle。详见[视频尾帧维护说明](../videoLastFrame.md)。
