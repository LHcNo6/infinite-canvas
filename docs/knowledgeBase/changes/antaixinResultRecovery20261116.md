# 安泰信成品下载恢复与视频提交保护

日期：2026-11-16。

## 已证实问题

后台截图确认八次图片生成均成功，本地均在下载CloudFront成品时连接超时；直连CDN根目录复现`UND_ERR_CONNECT_TIMEOUT`，系统代理可返回HTTP响应。Seedance 2.5原任务则明确返回参考图宽度不在300–6000px：本地素材实际193×289。Fast提交503没有取得上游任务ID，不能确认其是否生成或计费，不能与2.5尺寸错误混为一谈。

## 实际改动

- `generation.ts`：成品GET最多三次、每次60秒，重试网络/408/429/5xx，其他4xx不重试；未配置应用网络时连接失败可尝试系统代理，不覆盖明确配置。下载保存拆为可复用入口，仍保留100MB及MIME限制、路径边界和本次文件回滚。
- `calls.ts`、`tasks.ts`：带调用身份的图片/视频在下载URL成品之前原子保存地址和输出目录；列表只返回是否可下载，完整地址不进入前端画布或日志。恢复接口重新读取持久记录，并限制同一调用并发恢复；只调用下载保存入口，绝不调用生成。恢复后写同一调用结果，不创建新收费调用。
- `calls/recover.ts`、`nodeSkeleton.vue`：增加“重试下载（不重新生成）”，保存成功后显示路径。图片/视频生成节点允许用户“使用结果”，不会自动覆盖当前输出；处理中禁止切换。原“重试保存”继续只补写终态。
- 供应商宿主增加可选任务ID回调。安泰信视频取得ID后立即保存再轮询；提交5xx/408保存有界、脱敏原因与关联头，标记未知，仍不重试收费POST。
- 安泰信4.2.1在Seedance 2.5图片上传/提交前校验宽高300–6000px，压缩保留最短边300px；不自动放大小图。Fast未套用未经确认的2.5尺寸限制。
- 更新服务端新增文案词典；供应商、节点及脚手架文案遵循原插件语言边界。

## 验证

- 以原193×289实际素材调用安装适配器，返回明确尺寸错误，发生在上传和生成提交之前。
- 使用新下载保存入口读取后台已生成图片；八张均找回并成功解码，JPEG为2048×2048，PNG为1024×1024，没有重新生成。清单位于本机`outputs/diagnostics/recoveredImages/`。
- 原CDN根地址经新逻辑约12秒后得到HTTP403；根地址403只证明直连失败后代理链路可达，不代表原图片失效。真实图片内容下载使用站内成品地址验证。
- Server、Web、节点脚手架、图片/视频生成节点类型检查通过；Server（含MCP）、Web及全部节点构建通过，开发节点产物已同步。Web保留原有配置加载与大分块提示。

- 重启源码后端后，实际失败调用的持久记录返回`canDownload=true`，列表不包含原始成品URL。在Ego Lite打开原`videoComposeQA`项目的场景节点，点击“重试下载（不重新生成）”，成功保存原JPEG（318036字节、2048×2048），同一调用记录变为成功、清除恢复URL并出现“使用结果”。未点击采用按钮，当前画布输出保持原值。截图保存在本机`outputs/diagnostics/antaixinRecoveryDialog.png`。
- 此次对照用户提供的任务ID/时间和已验证站内地址，备份后补齐了上述一条旧调用的恢复字段，用真实成品验证恢复路径；其余历史调用未批量改写，八张图片另存成品目录。新请求自动保存成品地址的收费端到端流程未执行。
- 最终完成Server、Web类型检查及构建，全部节点开发产物已同步；Server直接启动源码开发服务，Web开发服务已重启。`http://localhost:3000/`、`http://localhost:5173/`及图片/视频生成节点文件接口均返回HTTP200，`git diff --check`通过。刷新地址：[本地开发页](http://localhost:5173/)。

## 边界

不发起新的收费生成验收；未验证新的真实5xx正文、真实视频成品下载、写盘失败、取消中断、多结果部分失败及多用户并发。上游503、服务故障、余额计费和临时链接过期无法由本地保证消失。只保存任务ID但未返回成品的任务不自动恢复轮询；无调用身份的同步工具请求及非URL/混合字节结果未增加持久恢复。历史丢失的URL不会自动补齐；此次仅根据用户提供的真实地址/任务ID找回成品。

未修改、构建或启动桌面/移动端，未远程推送。相关主题：[安泰信模型](../antaixinModels.md)、[模型调用记录](../nodeModelCalls.md)、[生成等待](../generationWaiting.md)。
