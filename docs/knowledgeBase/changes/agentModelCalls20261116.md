# Agent 查看生成节点调用记录与重试下载

日期：2026-11-16。

## 本次行为

图片、视频生成节点更新为 2.1.0，提供两个由画布工具发现和调用的节点函数，不新增独立工具插件、配置项、依赖或服务：

- `node:getModelCalls`：合并独立持久记录与旧画布记录，相同 ID 以服务端为准；支持 `callId` 详情、`offset/limit` 分页，默认 10 条、最多 50 条。服务端不可访问时明确报错。结果只保留公开字段，隐藏内部恢复信息和详情中的网址；列表／单条详情上限分别为 4000／16000 字符。
- `node:retryDownload`：使用指定调用的原成品地址，或在 `canSupplyResult` 为 true 时使用用户提供的 HTTP(S) 成品直链。只恢复原成品，不进入供应商生成接口，不覆盖当前节点输出；用户仍在窗口点击“使用结果”。记录已有成功结果时返回 `alreadySaved=true`，不再次下载，不额外验证文件存在。未知或缺地址时返回明确下一步，支持原任务查询的调用引导到现有窗口入口。

下载成功返回 `callId/files/call/outputChanged/alreadySaved/message`，`outputChanged=false`；原始恢复 URL 不进入返回值。Agent 本轮未新增原任务查询或采用结果的函数。音频节点的现有函数保持原范围。

## 实现位置

- `packages/nodeScaffold/src/nodeAi.ts`：集中记录请求、工作区／画布／节点绑定及合并；请求传递取消信号。
- `packages/nodeScaffold/src/nodeSkeleton.vue`：调用窗口复用上述入口，保留手动查询、补充链接下载、补写终态和使用结果。
- `packages/nodeShared/src/useNodeGeneration.ts`：注册两种媒体节点共用的函数、执行参数校验和公开结果投影。
- 两个生成节点的 `src/index.vue`、`package.json`、`readme.md`：接入能力、升级版本并说明使用边界。
- [插件开发指南](../../pluginDevelopment.md)、[模型调用记录维护](../nodeModelCalls.md)及知识库索引：同步接口与维护说明。

服务端恢复接口沿用已有实现、同一调用锁和 240 秒上限；节点调用最多等待 120 秒。取消或超时可能留下仍在进行的后端下载，Agent 必须先重读记录，不能推断下载已停并自动重试。
